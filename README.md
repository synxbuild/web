# synx build · web

Official website for synx build (synxbuild.com). Its goal is to bring in new clients.

- Stack: Next.js (App Router), Tailwind CSS 4, Geist.
- Brand tokens live in `app/globals.css` and match the panel at app.synxbuild.com.
- Hosting: Vercel team "Synx Build", separate project from the panel.

```bash
pnpm install
pnpm dev
```

Node 22 (see `.nvmrc`).
